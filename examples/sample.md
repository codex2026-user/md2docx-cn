# 中文 Markdown 转 Word 示例

这是一个完全在本地运行的小工具。它把常用的 Markdown 文章结构转换为排版整洁的
Word 文档，适合投稿、方案和内容归档。

## 主要特点

- 中文宋体正文和清晰的标题层级
- 自动首行缩进与舒适行距
- 项目符号、编号步骤和引用样式
- 不上传文件，不需要账号或 API 密钥

## 使用步骤

1. 准备 UTF-8 编码的 Markdown 文件
2. 运行 md2docx-cn 命令
3. 在 Word 中检查并提交最终版本

> 免费版解决通用排版；单位模板、投稿格式和批量流程可提交 Issue 定制。

### 已知边界

首个版本暂不支持复杂表格、公式、脚注和嵌套列表。
