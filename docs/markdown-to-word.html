Markdown 转 Word：三种方法与中文排版指南

临时转换一篇文章和长期批量处理，适合的方法并不相同。下面比较三种常见路线， 并给出中文文档最容易出问题的排版检查项。

先看结论

  • 只转换一次、格式要求不高：可以复制到 Word 后手动整理。
  • 需要完整 Markdown 生态和丰富参数：使用 Pandoc。
  • 主要处理中文文章、希望开箱即用：使用 md2docx-cn。
  • 必须匹配单位或投稿模板：先拿到目标样例，再做专用模板适配。

方法一：复制到 Word 后手动整理

适合一次性任务

优点是马上能做，缺点是每次都要重复

对于短文，可以先在 Markdown 编辑器中预览，再复制到 Word。之后手动统一标题、 正文字体、首行缩进、行距和页边距。

这种方式不需要安装工具，但内容较长、列表较多或需要多次修改时，容易出现样式 不一致，也难以复用同一套规则。

方法二：使用 Pandoc

适合熟悉命令行的用户

通用能力强，可继续配置参考文档

Pandoc 是通用文档转换工具，支持 DOCX 输出。安装后，基础命令如下： 

pandoc article.md -o article.docx

复杂场景可以继续研究参考文档、元数据和过滤器。准确参数以 Pandoc 官方手册为准。

方法三：使用 md2docx-cn

中文文章推荐

把常见中文排版规则放进转换流程

md2docx-cn 聚焦一至三级标题、正文、项目符号、编号步骤和引用等常用文章结构， 自动应用中文字体、首行缩进、行距、页边距和标题层级。 

python -m pip install "https://github.com/codex2026-user/md2docx-cn/releases/download/v0.1.1/md2docx_cn-0.1.1-py3-none-any.whl"
md2docx-cn article.md -o article.docx --author "你的名字"

输入文件只在本机处理，不需要账号，也不上传文档。

转换后要检查什么

  1. 标题层级：一级、二级、三级标题是否保持清楚的字号差异。
  2. 中文字体：正文与标题字体在交付电脑上是否可用。
  3. 段落节奏：首行缩进、行距和段前段后是否符合目标要求。
  4. 列表与引用：编号是否连续，换行后是否对齐，引用是否明显区分。
  5. 目标模板：投稿或单位材料应以对方最新模板为最终标准。
